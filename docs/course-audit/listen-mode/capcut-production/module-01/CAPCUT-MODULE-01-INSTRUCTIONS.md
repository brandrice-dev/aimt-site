# CapCut pass — Module 1 (full module, one pass)

1. Open CapCut Desktop.
2. New/blank project.
3. Import: `module-01-capcut-master.wav` (in this folder).
4. Put the entire file on the timeline as ONE audio clip.
5. Do NOT cut, trim, move, or delete silent gaps.
6. Audio > Basic:
   - Volume = **0.0 dB**
   - Fade in = **0.0s**
   - Fade out = **0.0s**
   - Normalize loudness = **ON**
7. Enhance voice = **ON**, Intensity = **75**
8. Reduce noise = **ON**
9. Isolate voice = **OFF**
10. Audio translator = **OFF**
11. No voice changer / EQ / pitch / speed / other effects.
12. Export **audio only**.
13. Prefer **FLAC** (or WAV) — lossless.
14. Save the export into this folder's `intake/` subfolder as:

```
docs/course-audit/listen-mode/capcut-production/module-01/intake/module-01-capcut-master-processed.flac
```

That's it — one CapCut pass for the whole module. No manual splitting
needed; Claude re-splits it automatically once it's in `intake/`.
