# CapCut proof — owner instructions

1. Open CapCut Desktop.
2. Create/open a blank project.
3. Import: `module-01-capcut-proof-master.wav` (in this folder).
4. Add it as one audio clip.
5. Select the audio.
6. Turn ON: **Enhance Voice**.
7. Start around **50%**, unless you already know the setting you used before.
8. Turn ON: **Loudness Normalization** — only if that's part of your normal
   audio-enhancement treatment.
9. Leave OFF: noise reduction, voice isolation, reverb, voice effects,
   EQ presets, pitch correction, any other enhancement.
10. Export **audio only**.
11. Prefer **WAV** if CapCut offers it.
12. Save the export to this folder as:

```
docs/course-audit/listen-mode/capcut-test/module-01/intake/module-01-capcut-proof-processed.wav
```

That's it — no manual splitting needed. Claude re-splits it automatically.
