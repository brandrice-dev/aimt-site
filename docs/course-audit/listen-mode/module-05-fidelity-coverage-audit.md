### Judgment call flagged for owner review

The 4-scenario signature interaction offers 3 button choices per scenario
(1 correct, 2 incorrect), each with its own feedback sentence in
`M5_DECISION_ANSWERS`. This rebuild narrates **all 3 options and all 3
feedback sentences per scenario** (not just the correct one), because the
incorrect-choice feedback carries real teaching reasoning — structurally the
same as the "mistake → better move" pairs already fully narrated in 5.9. This
runs longer than v1's single closing sentence, but strict fidelity is the
explicit priority over pacing. Flagging this choice explicitly since it's the
one place this audit exercises judgment rather than mechanically transcribing
a 1:1 visible list.
