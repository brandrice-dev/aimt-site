# AIMT — Copy & Claims Audit (D3 / D7 / D8)

*Verification: live web search, sources cited with dates. Companion to Design-Audit-Charter.*

## 🔴 Fix before launch — claims that are false or unsupportable as written

### 1. "Every AIMT graduate receives a printed and digital certificate" (index.html)
**Problem:** The system issues digital certificates only. No print fulfillment exists.
**Fix (choose one):**
- (a) Copy: "Every AIMT graduate receives a digital certificate with a unique,
  independently verifiable credential ID" — stronger claim anyway, and true.
- (b) Or actually offer print (adds fulfillment cost/ops — a real decision, not a copy edit).
**Recommendation: (a) now; revisit print as a premium touch post-launch.**

### 2. The "Estimated AI task exposure by field" chart (index.html)
**Problem:** Displays decimal-precision figures (35.8%, 34.3%, 28.4%, 26.9%, ~4%)
with no source. I could not match these numbers to any published study. Unsourced
decimal statistics are a credibility landmine — one skeptical prospect (or
competitor) asking "source?" and the institute's whole accuracy posture wobbles.
**Fix:** Rebuild the section on the VERIFIED STAT BANK below — the true, citable
numbers tell the same story, arguably better. Add a small source line under the
graphic ("Sources: ILO 2025; Pew Research Center; BCG 2026").

### 3. "Mobile-first" (course cards, index + courses)
**Problem:** D9 (mobile parity pass) has not been performed. Claiming
"mobile-first" before the mobile audit is aspirational, not factual.
**Fix:** Either soften to "self-paced · learn on any device" until D9 completes,
or keep the copy and treat D9 as a launch blocker. Recommendation: soften now,
restore "Mobile-first" as a claim AFTER the mobile pass verifies it.

### 4. "Aisha M." + percentage figures (headspa-mastery.html)
**Problem:** A name with stats (47%, 72%, 58%...) appears in the page. If this
is a mock/demo UI graphic, ensure it cannot be read as a testimonial or student
outcome — fabricated personas presented as real people/results create FTC
endorsement-guide exposure.
**Action:** Brandon to confirm what this section is. If decorative demo UI:
either label it clearly as illustrative or replace with abstract data. If it
reads as a testimonial: remove until real student testimonials exist.

### 5. "AIMT · Cohort 01" (certificate mock, index.html)
**Problem:** "Cohort" implies scheduled group intakes; the product is self-paced.
Minor, but it's a promise-shaped word.
**Fix:** Drop or replace with "Founding Class" styling only if you intend to
honor it as a designation. Simplest: remove.

## 🟠 D8 — Blanket-claim scoping violations (course facts stated institute-wide)

### 6. "12-module certification programs that build real competency" (index.html)
Plural "programs" + "12-module" = claims every AIMT course is 12 modules.
This is the exact violation Brandon flagged. **Fix:** "Focused certification
programs that build real competency — not highlights, not tips." Move "12
modules" to HeadSpa-specific contexts only (course card, course page), where it
already correctly appears.

### 7. Audit rule going forward (add to charter enforcement):
Institute-level claims (allowed anywhere): verifiable credentials · in-course AI
tutor · self-paced · checkpoint-gated completion · lifetime access · one-time
pricing. Course-level claims (only beside the specific course): module counts,
hours, price, curriculum specifics, service step counts (17 steps).

## 🟡 Tension checks (not false, but decide the framing)

### 8. "One certification at a time... Not a library — an institute" (index)
vs. courses.html: "HeadSpa Mastery ecosystem... mini-courses in development"
and FIVE numbered certifications displayed. Not contradictory (sequential
release ≠ single product) but the copy should pick one story: recommend
"released one at a time, done right" phrasing everywhere, which makes the
5-certification roadmap a feature of the discipline claim rather than a
contradiction of it.

### 9. Graduate network claims (index)
"AIMT graduates can open doors for each other... network is being built
intentionally" — currently honest (hedged as being built). Keep the hedge until
graduates exist. Do NOT let future copy edits strip the hedge.
